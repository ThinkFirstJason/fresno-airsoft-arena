# Fresno Airsoft Arena — Website Concept

Spec mockup for Fresno Airsoft Arena, an outdoor airsoft field in Kerman, CA. Styled like a field-issued range card: sand paper, olive ink, hairline rules. The logo's red is used only for actions and its blue only for links.

**Live:** https://thinkfirstjason.github.io/fresno-airsoft-arena/

- Single static `index.html`, no build step
- Design language for reuse: [DESIGN.md](DESIGN.md)
- Photos are the field's own (supplied by the client pitch). Logo is theirs.

Address, phone, email, hours and "first game free" come from public listings (Yelp, AirsoftC3). Hours differ slightly between listings. **Prices and chrono limits are placeholders.**
